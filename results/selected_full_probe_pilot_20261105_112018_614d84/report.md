# 선택한 전체 probe 출력 파일럿 결과

이 보고서는 입력 PCA 유지·출력 PCA 제거의 **후속 반복 검증 후보**를 정리한다. 모든 실험을 통틀어 검증된 최적 모델이라는 뜻이 아니다. 같은 결과를 관찰하며 설계를 발전시킨 탐색 실험이며, 성능을 보고 후보를 선택했다.

## 구성과 평가 범위

- 시간·용량별 in vitro 반응을 조건 슬롯과 관측 mask로 보존
- source 반응: 학습 MinMax → 입력 PCA 최대32 → score 표준화
- 목표 in vivo 시간·용량·단위·등급 + 선택적 구조 특징 concat
- target: 전체3,453개 probe 반응, 학습 probe평균·공통RMS의 가역변환만 적용
- 외부5fold 중 fold0 **하나**, split seed42·model seed42
- 내부학습89 / 검증23 / 테스트28 화합물, 테스트target336조건
- 최대100epoch에서 validation RMSE로선택 후112개화합물로전처리·모델재학습
- 총9조건 완료. 기존 5-fold × 3-seed 반복표와 직접 순위 비교하지 않음

## 현재 후보와 해석

- 학습모델중가장낮은RMSE·MAE·가장높은Pearson: **입력PCA + Morgan MLP**, RMSE0.288869/MAE0.169218/Pearson0.209523.
- Morgan DDPM은RMSE0.289531, Morgan cGAN은0.289752. DDPM이MLP보다우수하다는결과는아님.
- 학습모델중Macro-F1최고는**구조없는MLP34.64%**. Morgan MLP가모든지표에서최고는아님.
- 시간×등급훈련평균은RMSE0.287834/MAE0.169098/Pearson0.231368/Macro-F137.90%로학습모델보다좋았음.
- 구조정보추가는각모델의이번holdout RMSE를낮췄지만분류F1까지일관되게개선하지않음.
- MLP/cGAN여러 조건이 epoch 100을 선택했으므로 학습 상한의 영향을 검토해야 함.
- 후속은이설정을고정한화합물5fold/초기화반복검증. 독립확증성·유의성·간독성/pathway예측은입증되지않음.
