# 入力 PCA 차원 내부 검증

사용자 서버 로그: 구조 없는 MLP에서16/32/64/128차원 × 모델seed42/43/44, 총12회 학습 완료. 같은 내부학습89/검증23 화합물을 사용하고 외부테스트28 화합물은 평가하지 않았다. 출력3453 probe 유지. PCA/scaler는 내부학습만 적합한다.

평균 검증 RMSE:16차원0.310904 /32차원0.311164 /64차원0.309657 /128차원0.309946. 64차원이 이번 비교에서 선택됐다. 설명분산은 각각49.62/57.97/66.26/76.47%. 단일 내부 분할에서 초기화3회 반복한 것이며 모든 모델에 대한 최적 차원 증명은 아니다. 전12회에서100epoch가 선택돼 학습 상한의 한계가 남는다.

by_seed_reported.csv는 로그의 dict에서 원문 정밀도로 추출했고 summary_reported.csv는 화면의6자리 요약이다. 둘을 다시 집계하면 표시 반올림 차이가 날 수 있다. 로그에 출력된 실행 커밋은ac8a2d2이나, 차원 비교는 저장소 기본 실행기가 아니라 대화에서 제공한 executed_cell.py 래퍼로 수행했다. 실제 서버 래퍼 파일과 해당 hash는 이번 첨부에 없으며 독립 확인하지 않았다. 원본 로그만 확보했고 원시 예측 재평가나 재학습은 하지 않았다.
