# 전체 시간·용량 PCA64 실험의 성능 분석

분석 범위는 조건별 입력 PCA64, 출력 3,453개 probe, 네 구조 조건 × MLP/cGAN/DDPM의 180개 학습 조건이다. 사용자 서버 로그와 저장소 코드를 대조했으며, 새 학습이나 예측 재생성은 하지 않았다. 원시 예측 배열을 독립 재평가한 결과는 아니다. 24시간·High toy 결과는 별개로 취급한다.

## 확인한 현상

### 1. 추가 입력이 조건만 모델을 안정적으로 넘지 못했다

입력 기여도 실험의 MLP 평균 RMSE는 다음과 같다.

| 입력 | RMSE |
|---|---:|
| 목표 조건만 | 0.292199 |
| 목표 조건 + in vitro | 0.294091 |
| 목표 조건 + Morgan | 0.292910 |
| 목표 조건 + in vitro + Morgan | 0.292321 |
| 시간·등급별 훈련 평균 반응 | 0.288403 |

Morgan을 추가하면 in vitro 모델보다 0.001770 개선되지만, 조건만 모델보다 좋지는 않다. 이는 현재 입력 표현과 학습 방식에서 추가 정보의 이점을 충분히 확보하지 못했다는 결과다. in vitro나 구조 정보 자체가 쓸모없다는 증거는 아니다. 모델 seed 반복은 같은 화합물 분할에서 이루어졌으므로 독립 데이터 반복으로 해석하지 않는다.

### 2. MLP·cGAN의 학습 손실과 주 평가 지표가 다르다

코드상 MLP는 MAE, cGAN 생성기는 10×MAE + 2×BCE로 학습하고, epoch는 검증 RMSE로 선택한다. MAE는 조건부 중앙값, MSE는 조건부 평균에 대응하므로 드문 큰 반응에서 다른 예측을 선호할 수 있다. 실제로 조건만 MLP는 평균 기준선보다 MAE가 낮지만(0.170968 대 0.171470), RMSE는 높다.

이는 손실과 평가 지표의 차이를 점검할 근거다. MSE로 바꾸면 성능이 개선된다는 검증은 아직 없다.

### 3. 큰 반응을 거의 예측하지 않는다

절대 반응 0.5 이상인 실제 요소는 5.8884%인데 Morgan–MLP의 해당 예측 비율은 0.1345%다. 큰 변화를 놓치는 보수적인 예측이라는 현상은 확인된다. 다만 작은 반응이 많다는 사실만으로 전체 제곱오차에서도 그 영향이 크다고 결론 내릴 수 없다. 반응 크기별 오차 기여를 계산해야 한다.

낮은 Pearson 상관도 진폭 축소만으로 설명할 수 없다. 완벽한 비례 예측이라면 진폭이 작아도 Pearson은 높다. 유전자별 반응 패턴의 불일치도 살펴야 한다.

### 4. PCA64여도 최종 모델은 작지 않다

64차원은 각 in vitro 조건의 발현 표현이다. 여러 조건의 표현·메타데이터·관측 표시를 연결하고 목표 조건과 구조 블록을 더하면, 로그상 최종 입력은 6,697–6,769차원이다. MLP/DDPM 명목 파라미터는 약 218만–220만 개이고 내부 학습 화합물은 89개다. 같은 화합물의 여러 목표 조건이 새로운 독립 화합물은 아니다.

모델 복잡도와 데이터 규모의 불균형은 일반화 문제의 후보다. 그러나 비활성 입력 열도 있으므로 명목 파라미터 수만으로 과적합을 입증할 수 없다.

### 5. MLP·cGAN은 학습 상한 선택이 많다

원본 로그에서 180개 완료 조건의 선택 epoch를 집계했다.

| 모델 | 조건 수 | 100 epoch 선택 | 선택 epoch 분포 |
|---|---:|---:|---|
| MLP | 60 | 49 | 40:2, 60:4, 80:5, 100:49 |
| cGAN | 60 | 59 | 80:1, 100:59 |
| DDPM | 60 | 2 | 1:13, 20:1, 40:25, 60:12, 80:7, 100:2 |

학습이 충분히 끝났는지 점검할 단서이며, 학습 부족의 확정 증거는 아니다. 테스트 결과를 보며 epoch를 늘리기보다 저장 모델의 학습·평가 오차와 내부 검증 곡선을 먼저 본다.

### 6. DDPM의 일부 실패는 별도로 분석해야 한다

fold 1/model seed 43에서 내부 검증 RMSE는 약 0.277이었지만, 최종 재학습 후 테스트 RMSE는 basic 0.516634, Morgan 0.439345, descriptor 0.738252, both 0.600131이었다. 같은 분할·seed의 MLP와 cGAN은 약 0.287–0.290이었다. TNFÉø와 tunicamycin 등에 큰 오차가 집중됐다.

이미 수행한 고정 모델 진단에서는 다음이 확인됐다.

- 두 화합물의 PCA 축별 score는 학습 범위 안이었다. 이것만으로 입력 분포 문제가 배제되지는 않는다.
- 학습에서 관측하지 못한 입력 슬롯을 제거해도 네 구조 조건 모두 전체 RMSE가 악화됐다. 슬롯 제거가 해결책이라는 가설은 지지되지 않았다.
- 생성 난수를 바꿔도 큰 오차가 반복됐다. 특정 샘플링 난수 하나만의 문제로 보기 어렵다.

내부 검증 모델과 최종 재학습 모델은 서로 다르다. 따라서 내부 검증 점수를 최종 모델의 검증 성능으로 해석하면 안 된다. 아직 확인할 부분은 최종 모델의 학습 집합 예측, 학습 방식의 노이즈 복원 성능, 자유 생성의 단계별 예측 범위다. DDPM의 노이즈 복원 MSE와 생성 결과 RMSE도 서로 다른 평가다.

## 아직 원인으로 단정할 수 없는 설명

- **PCA 손실:** 같은 분할의 MLP 반복 비교에서는 PCA64가 전체 입력보다 RMSE가 낮았다. 입력 스케일과 모델 크기도 달라 PCA만의 인과 효과는 아니며, 생성 모델 전체로 확대할 수 없다.
- **시간별 pair 부족:** pair 방식 MLP도 목표 조건만 모델을 넘지 못했다. 입력 연결 방식만으로 현상을 설명하기 어렵다.
- **출력 3,453개의 규모:** 무작위 256개 출력 실험은 별도의 24시간·High toy이므로 이 전체 시간 실험의 원인 검증이 아니다.
- **단위·구조 누락·이름 문제:** 기록된 데이터 한계이지만 현재 성능 저하의 인과적 원인으로 확인되지는 않았다.
- **변화량 예측:** 입력과 출력 모두 처리군−대조군이다. 차분에는 대조군의 측정 잡음도 반영될 수 있지만, 동일 코호트의 통제 비교 없이 실제 원인으로 단정하지 않는다. 절대 발현을 예측한 AIVIVE의 RMSE와 직접 순위를 비교하지 않는다.

## 다음 분석의 우선순위

새 모델을 만들기 전에 저장 예측으로 다음을 계산한다.

1. 실제 반응 크기별 오차·편향·전체 SSE 기여도: 큰 변화를 놓치는 정도 확인.
2. 동일 화합물·시간·용량 등급별 기준선 대비 대응 오차: 추가 입력이 도움 되는 조건 확인.
3. 동일 최종 모델의 학습·테스트 예측과 각 집합의 기준선 비교: 학습 적합과 일반화 문제 구분.
4. DDPM의 노이즈 복원과 자유 생성 분리: 실패가 학습 단계인지 역확산 단계인지 점검.

실제 반응 크기로 나눈 분석은 정답을 이용한 사후 기술 분석이며 DEG 검정이 아니다. 좋지 않은 seed나 화합물을 삭제해 주 평가를 대체하지 않는다. 현재 전체 시간 모델의 학습 예측·반응 크기별 SSE 결과까지 확보된 것은 아니다.
