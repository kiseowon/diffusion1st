# 기준선은 무엇을 가정하는가?

이 연구의 정답은 probe별 vivo 처리군−같은 화합물·단위·시간 대조군의 조건 평균 반응입니다. 기준선은 각각 다른 질문에 답합니다.

| 기준선 | 예측값 | 비교 질문 |
| --- | --- | --- |
| 변화 없음 | 모든 probe의 반응0 | 처리 효과가 없다고 하는 것보다 나은가? |
| 시간×등급 훈련 평균 | 같은 목표 vivo 시간·용량 등급의 훈련 화합물 평균 반응 | 알려진 실험 조건의 공통 반응보다 나은가? |
| 목표 조건 Ridge | 목표 dose·time·unit·level을 입력한 규제 선형 예측 | 현재 잔차 모델의 기본 예측에 추가 보정이 기여하는가? |

변화 없음은 절대 발현0이나 vitro 발현=vivo 발현이라는 뜻이 아닙니다. 처리에 따른 반응이0이라는 가정이며, 예측할 때 테스트 실제 대조군을 입력받지 않습니다. 실제 대조군은 정답 반응을 구성할 때 사용합니다.

## 시간×등급 평균의 구체적 예

새 화합물의 **vivo24시간·High** 반응을 예측한다고 가정합니다. 아래는 실제 데이터가 아닌 한 probe의 설명용 값입니다.

| 훈련 화합물 | 24시간·High의 실제 반응 | 화합물 내 평균 |
| --- | --- | ---: |
| A | +0.2, +0.6 | +0.4 |
| B | +0.8 | +0.8 |

기준선은 화합물 내 평균을 먼저 낸 후 `(0.4+0.8)/2=0.6`을 예측합니다. 조건3개를 바로 평균하는0.533과 다릅니다. 조건이 많은 화합물이 더 큰 비중을 차지하지 않도록 한 정의입니다. 실제로는3,453개 probe 각각 이 계산을 하므로 예측값은 벡터입니다. target이 여러 source pair에 반복돼도 같은 target을 중복 집계하지 않습니다.

같은24시간·High를 묻는 새 화합물은 모두 같은 기준선 벡터를 받습니다.48시간·High 또는24시간·Low라면 해당 훈련 group의 다른 평균을 사용합니다. group에 없는 시간을 보간하지 않고 코드가 중단합니다.

## 이 비교가 허용되는 이유와 한계

예측할 vivo 시간·용량 등급은 이 연구의 입력 조건으로 사전에 주어집니다. 기준선도 모델이 알고 있는 이 정보만 이용합니다. 평균에는 외부 테스트 화합물의 실제 반응을 넣지 않습니다. 통계적으로는 알려진 조건에 따른 훈련 평균을 사용하는 단순한 조건부 예측 기준선입니다. 특정 IVIVE 논문이 의무적으로 쓰는 표준 기준선이라고 주장하지 않습니다.

High는 **같은 물리적 투여량**이 아닙니다. 기존 메타데이터의 상대적 용량 등급이며 화합물마다 수치 용량이 다를 수 있습니다. 현재 평균 기준선은 단위를 추가로 구분하지 않고 목표시간×등급으로 묶습니다. 단위·등급 정의와 그 한계를 보고해야 하며, 실험 조건을 바꿔도 통용되는 생물학적 법칙이라고 해석하면 안 됩니다.

기본적인0반응 기준선만 사용하면 처리효과0보다 낫다는 결론은 낼 수 있지만, 화합물의 개별 발현·구조를 사용한 추가 이점까지 입증하기 어렵습니다. 따라서0반응과 조건별 평균을 함께 제시합니다. 현재 MLP/cGAN/DDPM은 공통Ridge 위의 잔차 보정이므로 Ridge의 기여도 드러나야 합니다. 발표 main표의 형식은 단순화할 수 있어도 Ridge가 포함된 구조와 기준 결과를 설계/보충자료에서 생략하지 않습니다.
